### 🚀 Selected Projects

**🀄 FatesGate — Taiwanese Mahjong AI** — C++23
A 16-tile Mahjong playing engine built on Monte Carlo Tree Search, with importance sampling, a transposition table, and an opponent deal-in model. Tuned for speed with per-thread tree parallelism and a profiled rollout inner loop. **Gold (TAAI 2023) and multiple tournament medals — see above.**

**♟️ Dark Chess / EinStein würfelt nicht! engines** — C++
Bitboard-based search engines using alpha-beta and expectiminimax with chance nodes, validated against gold-standard test suites.

**🧘 Motion-controlled fitness game** — Unity, C#
A Kinect / BlazePose pose-driven yoga game with data-driven joint-angle scoring and webcam (RGB) skeleton input.
